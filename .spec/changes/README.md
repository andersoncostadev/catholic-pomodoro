Esta pasta reúne as specs em andamento.

- `NNN-descricao-da-mudanca/spec.md` — arquivo principal da mudança.

Toda mudança funcional ou visual deve ter uma spec ativa antes da implementação, salvo ajuste de emergência documentado e revisado.
